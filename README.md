## 📌 O que é?

Este projeto é uma Landing Page responsiva criada para mapear a **Evolução no Desenvolvimento de Software nos últimos 20 anos (2007 a 2026)**. O objetivo principal é demonstrar de forma visual e estruturada a transição *"Da Programação Monolítica à Co-criação com IA"*, abordando a evolução de linguagens, paradigmas, arquiteturas de distribuição e transformações no raciocínio lógico da engenharia de software.

**Objetivos alcançados:**
* **Semântica HTML5:** Estrutura completa construída com tags semânticas (`<main>`, `<section>`, `<article>`) priorizadas sobre elementos genéricos.
* **Design Temático:** Interface inspirada em editores de código (*Code Editor / Dracula*), utilizando fontes monospace e paleta visual focada em UI/UX.
* **Linha do Tempo Visual:** Mapeamento do período 2007–2026 dividido em 4 quinquênios com imagens acessíveis e tags decorativas.
* **Tabela Comparativa:** Análise direta entre a infraestrutura de 2007 e os padrões de 2026.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização modular com Flexbox, variáveis CSS (`:root`), tipografia monospace, suporte a media queries e layout responsivo.
* **Git & GitHub:** Controle de versão e hospedagem do repositório.
* **GitHub Pages:** Deploy e publicação online da aplicação.
